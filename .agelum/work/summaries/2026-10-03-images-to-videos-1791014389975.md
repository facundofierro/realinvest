# Images to videos — summary

Replaced the static images in two landing cards with looping videos generated from them via fal (`genmedia`, `fal-ai/veo3/image-to-video`, 4s, no audio, 720p).

## Videos
- `apps/landing/public/videos/buyers-reactivation.{mp4,webm}` — from `buyers-reactivation.webp`. The source was padded to 16:9 with the matching lavender background (Veo needs 16:9) and the output cropped back to 4:3 (960x720).
- `apps/landing/public/videos/service-3d.{mp4,webm}` — from `service-3d.webp`, cropped to 3:2 (960x640).
- Each is ~130–225 KB, re-encoded without audio. Generation cost ≈ $0.40/s × 4s × 2.

## Code
- New `apps/landing/src/components/card-video.tsx`: muted looping `<video>` with the original webp as poster. It plays only while in view and stays on the poster under `prefers-reduced-motion`.
- `know-your-buyers.tsx`: the right-hand card now uses `CardVideo`.
- `services.tsx`: the `3d` entry has a `video` field and renders `CardVideo`. The other cards still use `<Image>`.
