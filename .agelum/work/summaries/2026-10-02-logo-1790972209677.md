# Logo — summary (2026-10-02)

## Status

Done. Concept 1, "Fold", was chosen and is applied across the project. One listed asset was deliberately left alone (see "Not changed").

## The logo

A two-tone V whose right stroke rises above the left, followed by "est" and an optional "REAL ESTATE" subtitle. Palette unchanged: `#E879F9`, `#A21CAF`, `#5B1187`. Lettering is Geist Bold / SemiBold converted to outlines, so no font is needed at render time.

The four original proposals remain in `.agelum/doc/docs/specs/logo/logo-proposals.html`.

## Changes

- `packages/ui/src/components/brand/vest-logo.tsx` — rewritten. Same `VestLogo` name, same `showSubtitle` and `forceWhite` props, same 200x200 viewBox, so the wallet and admin bottom navs and the test gallery need no changes. The old drop-shadow filter (which used a duplicated SVG id) is gone. Adds `VEST_BRAND_COLORS`.
- `packages/ui/src/components/brand/vest-real-state.tsx` — subtitle text "Real State" corrected to "Real Estate". Component name unchanged.
- `packages/ui/src/assets/brand/` — new shared static assets for the future landing site: `vest-logo.svg`, `vest-wordmark.svg`, `vest-mark.svg`, white versions of each, `vest-app-icon.svg`, and a README.
- `packages/ui/package.json` — new export `@repo/ui/assets/brand/*`.
- `apps/wallet/src/app/favicon.ico`, `apps/test/src/app/favicon.ico` — regenerated (16, 32, 48, 256 px).
- `native/wallet/tauri/src-tauri/icons/` — all 16 files regenerated. They previously held the default Tauri placeholder icon.
