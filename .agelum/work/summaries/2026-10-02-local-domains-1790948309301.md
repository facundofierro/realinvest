# Local domains

Created HTTPS local domains with `agelum local-domains` (Caddy + /etc/hosts). Per user request, `.com` hostnames were used instead of the suggested `.test`, since Google OAuth rejects `.test`.

| App | URL | Port | Status |
| --- | --- | --- | --- |
| Wallet | https://local.wallet.realinvest.com | 47310 | ready |
| Admin | https://local.admin.realinvest.com | 47311 | ready |

- An initial `.test` wallet entry failed (no admin permission for /etc/hosts); it was deleted with `agelum local-domains delete`.
- `apps/wallet/README.md`: updated URL and Google OAuth redirect URI to the new domain.
- `.env.example`: added `AUTH_URL=https://local.wallet.realinvest.com`.

## Manual follow-up
- Register `https://local.wallet.realinvest.com/api/auth/callback/google` in Google Cloud Console.
- Set `AUTH_URL` in `.env.local`.
- `native/wallet/nextjs/package.json` still uses `NEXT_PUBLIC_API_URL=http://localhost:47310` (left unchanged).
