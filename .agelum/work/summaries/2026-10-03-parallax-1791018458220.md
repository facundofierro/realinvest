## Deviations from the plan

- **Hero timeline**: instead of `scroll(root)` with `0 100svh`, the hero effects use a named view timeline on the
  hero section (`--hero`, range `exit 0% exit 100%`), and the gap close uses the Problem section's own
  `view()` entry (`entry 0% entry 70%`). On desktop this is equivalent; on mobile, where the hero is taller than
  the screen, the plan's version would have faded the dashboard card to ~60% opacity while it was still
  mid-screen. The JS fallback computes the same progress.
- **`overflow-clip` instead of `overflow-hidden`** on every ancestor of a `view()`-animated element (blob
  sections, `FinalCta`, the Problem card and split frame, zoom wrappers). `overflow: hidden` creates a scroll
  container, which captures the `view()` timeline and freezes the animation.
- **Skyline range** is `entry 0% entry 100%` (plan: `entry 0% cover 60%`): `FinalCta` is the last section and
  might never reach `cover 60%`.
- **Tuned values**: badge drifts −40/−20/−55/−30px and phone drifts 30px (plan: up to −70px / 40px) so badges
  don't touch each other and phones stay inside their panels.
- `parallax-pan` keyframes from Phase 0 were not added: nothing uses them (the Problem photos use
  `parallax-drift`).
- The launch-day image wrapper clips without a border radius.
