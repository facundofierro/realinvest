# Fix build errors

## Changes
- `apps/wallet/src/components/pages/login-page.tsx`: moved the misplaced `"use client";` directive from the end of the file to the top (fixes the Turbopack build error).
- `apps/wallet/src/lib/api/trading.ts`: fixed a TS error (`buyUserId` undefined) -> `buyUserId: buyerUserId` in the trades insert.

## Verification
- `tsc --noEmit` in apps/wallet: clean.
- `next build`: compiles successfully (Turbopack) and TypeScript passes. The build then fails at "Collecting page data" for `/api/market/orderbook` with `Unable to open connection to local database ../db/wallet.db`. This is an environment issue (local SQLite DB file missing at build time), not a code error, and was not addressed.

## Follow-up: DB connection error at build
- Cause: `apps/wallet/.env.local` had `DATABASE_URL=file:../db/wallet.db`, which resolves to a non-existent `apps/db/wallet.db`. The DB lives at `packages/db/wallet.db`.
- Fix: changed to `file:../../packages/db/wallet.db` (file is gitignored, so this is a local change; other checkouts need the same value).
- Result: `pnpm run build` in apps/wallet now completes successfully.

## Follow-up: native/wallet/nextjs build (`kycStatus` not on `User`)
- Cause: the native app compiles `apps/wallet/src` via a path alias, but its tsconfig didn't include `apps/wallet/src/types/next-auth.d.ts`, so the NextAuth `User`/`Session` augmentation (with `kycStatus`) was missing.
- Fix: added `../../../apps/wallet/src/types/*.d.ts` to `include` in `native/wallet/nextjs/tsconfig.json`.
- Result: `pnpm run build` in native/wallet/nextjs succeeds.

## Follow-up: `pnpm dev` port conflicts
- Ports 8000/8001 were held by another project (`~/git/kserver`: dashboard and agelum-assistant Next servers), not this repo.
- Moved to high ports: wallet 47310, admin 47311, test 47312, native wallet 47313. Updated the `dev`/`start` scripts, `NEXT_PUBLIC_API_URL` in native/wallet/nextjs, `devUrl` in tauri.conf.json, and the wallet README (incl. the Google OAuth redirect URI, which must now be `http://localhost:47310/api/auth/callback/google`).
- Verified `pnpm dev` starts all four apps and `/login` returns 200 on 47310.
