# Summary: UI Fixes — 3D images for the 4 "Empezá simple" step cards

Plan: `.agelum/work/plans/2026-10-02-26_10_02-190041-UI Fixes-1790978753226.md`
(Certainty: High, Ambiguity: Low, so no clarifying questions were needed.)

## What was done

### Phase 1 — Image generation (fal.ai `fal-ai/nano-banana-pro`)
- Wrote 4 prompts in `.imagegen/prompts/` (scratch, gitignored): `step-demo`, `step-setup`,
  `step-launch`, `step-operation`. Each has one subject sentence, followed by the same shared
  boilerplate based on `payments-coin.txt`: soft 3D clay render, three-quarter view from slightly
  above, violet `#5B1187` / lilac `#EAD7F5` / white / gold palette, flat `#00FF00` key, and the
  usual bans (no reflections of the key, no glow or lens flare, no green outline, no shadow, no text).
  - Demo: desktop monitor with an abstract violet gradient screen
  - Implementación: a large violet gear and a small gold gear
  - Lanzamiento: violet flag, gold pole and finial, on a lilac base
  - Operación: headset with violet earcups, gold rims, lilac headband and mic boom
- Generated all 4 at 1:1 / 2K and cut them out at 256px with `.imagegen/cut` (chroma key plus a
  synthetic shadow).
- Checked the results visually on a light and a dark contact sheet. All 4 were accepted on the
  first pass: no green fringe or reflections, no stray text, and the style is consistent.
- Deployed to `apps/landing/public/images/step-{demo,setup,launch,operation}.webp` (8–13 KB each).

### Phase 2 — Component
`apps/landing/src/components/sections/how-it-works.tsx`:
- Added the `next/image` import and removed the now-unused `IconTile` / `IconName` import.
  `IconTile` is still used elsewhere (problem, launch-day, icon-bullets), so `icons.tsx` was not changed.
- Replaced the `icons` array with an `images` array of the 4 webp paths.
- Replaced `<IconTile …>` with a decorative `<Image alt="" width={256} height={256}
  className="mb-3 size-[84px] flex-none" />`, the same pattern as `payments.tsx`. The tinted tile
  background was dropped.

### Phase 3 — Verification
- `tsc --noEmit` for the landing app passes.
- The dev server at `https://local.landing.realinvest.com` returns 200 for both the static file
  and the `/_next/image` optimizer URL.
- In the browser, the cards in the `#como-funciona` section show the 3D images above unchanged
  titles and text (checked in the 1-column mobile layout).
