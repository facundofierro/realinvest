Minor choices (exact image size, whether to keep the tinted tile behind the image) are decided in the plan below; none requires user input.

## Phase 1 — Generate the 4 images

Work in `.imagegen/` (already set up; verify `.imagegen/` is in `.gitignore` and `venv` has pillow+numpy).

1. Check the CLI is authenticated: `genmedia models "nano banana" --limit 1`; if not, `genmedia setup --non-interactive --api-key "$FAL_KEY"`.
2. Write four prompt files with the Write tool, reusing the boilerplate of `.imagegen/prompts/payments-coin.txt` verbatim for the style/key/negative constraints, and only changing the subject sentence:
   - `.imagegen/prompts/step-demo.txt` — a soft 3D clay-like render of a modern desktop monitor on a slim stand, screen showing only abstract blurred violet gradient shapes (no text), body in lilac/white with deep violet #5B1187 accents and gold detail.
   - `.imagegen/prompts/step-setup.txt` — a chunky 3D clay-like gear / cogwheel pair (one large deep violet, one smaller gold) at a three-quarter angle.
   - `.imagegen/prompts/step-launch.txt` — a 3D clay-like flag on a short pole planted on a small rounded base, flag in deep violet with a gold finial and pole.
   - `.imagegen/prompts/step-operation.txt` — a 3D clay-like over-ear headset with a small mic boom, deep violet earcups with gold rims and a lilac headband.
   All four must share the same camera angle, material, lighting, and palette so they read as a set. Include the "no text/letters/numbers/logos" sentence, "centered with generous margin", "no shadow", "no glow/lens flare", "no green stroke/outline", and "green background is not a light source and must not be reflected".
3. Generate: `.imagegen/gen step-demo 1:1`, then `step-setup`, `step-launch`, `step-operation` (1:1, 2K).
4. Cut out at a size suitable for ~2x retina display of a ~72px slot: `.imagegen/cut step-demo 256` (same for the others).
5. Visually inspect each `raw/*.png` and `out/*.webp` (Read tool): check for green fringe, green reflections on glossy parts, residual glow rings, duplicated/odd objects, stray text, and style consistency across the set. Iterate by editing only the specific prompt line responsible (1–4 passes expected), regenerating with `gen` (it deletes the stale raw file first) and re-running `cut`.
6. When all four are accepted: `.imagegen/deploy step-demo`, `step-setup`, `step-launch`, `step-operation` → files land in `apps/landing/public/images/`.

## Phase 2 — Wire the images into the cards

Edit `apps/landing/src/components/sections/how-it-works.tsx`:

1. Add `import Image from "next/image";` (same as `payments.tsx`).
2. Replace the `icons: IconName[]` array (line 7) with an array of image sources, e.g. `const images = ["/images/step-demo.webp", "/images/step-setup.webp", "/images/step-launch.webp", "/images/step-operation.webp"];` and remove the now-unused `IconTile`/`IconName` import (line 2) — but only if no other use remains in this file.
3. Replace line 17 `<IconTile name={icons[i]} className="mb-4" />` with:
   ```tsx
   <Image
     src={images[i]}
     alt=""
     width={256}
     height={256}
     className="mb-3 size-[84px] flex-none"
   />
   ```
   (decorative image, hence empty `alt`, matching `payments.tsx`). The 84px size matches the existing coin precedent and is noticeably larger/richer than the old 52px tile; the pink `bg-tint` square is dropped since the 3D object has its own shadow. If the cards look unbalanced, adjust the size between 72–96px, keeping `mb-*` so the heading position stays visually consistent across all four cards.
4. Do not modify `IconTile` or `icons.tsx` — `IconTile` is used elsewhere on the page (verify with a grep for `IconTile` before removing anything; only the import in `how-it-works.tsx` should change).
