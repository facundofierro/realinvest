## Certainty assessment

**Level: Medium-High**

The work is a greenfield static marketing site in a well-understood stack (Next.js 16 / React 19 / Tailwind 4 / pnpm+Turbo). Copy is complete and approved, the scaffold pattern exists (`apps/test/*`, `apps/wallet/*`), shared UI (`@repo/ui`) is available, and the decision to use a new app is already made. Remaining risk is not technical: (a) the design (version C) is final and fully specified in this plan, (b) adding a table to `@repo/db` and a migration (existing drizzle flow in `packages/db/drizzle.config.ts:1-10`, scripts `packages/db/package.json:11-14`), (c) mixing the "Vest" logos with "Real Invest" copy, and (d) `@repo/ui` has no Accordion component (FAQ must be built with native `<details>` or a new Radix dependency).
